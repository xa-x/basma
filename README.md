# بصمة (Basma)

AI-powered branding for the Middle East. Create logos, packaging, and print-ready files in minutes.

## Stack

- **Next.js 15** — App Router, Turbopack, React 19
- **Tailwind CSS v4** — Modern utility-first CSS
- **AI SDK** — Vercel AI SDK with OpenAI
- **shadcn-style UI** — Custom components built on Radix UI
- **JSON Storage** — Fast MVP (SQLite ready for production)

## Quick Start

```bash
cd /Users/x/.openclaw/workspace/basma
npm install
npm run dev
```

Open http://localhost:3000
