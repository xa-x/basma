# بصمة (Basma)

AI-powered branding for the Middle East. Create logos, packaging, and print-ready files in minutes.

## Stack

- **Next.js 14** — App Router, RTL-first
- **SQLite + Drizzle ORM** — Fast, local development
- **Three.js** — 3D packaging mockups
- **AI Models** — Qwen, DALL-E 3, Stable Diffusion, Flux

## Quick Start

```bash
cd /Users/x/.openclaw/workspace/basma
npm install
npm run db:push    # Create SQLite database
npm run dev        # Start dev server
```

Open http://localhost:3000
